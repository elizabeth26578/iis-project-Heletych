# Лабораторна робота №5
## Механізм виведення та підсистема пояснень

**Тема проєкту:** Інтелектуальна інформаційна система діагностики несправностей автомобіля.

### 1. Прямий ланцюг виведення
Реалізовано пряме логічне виведення засобами CLIPS у файлі `src/forward_trace.py`. Для тестового коду P0300 зафіксовано 10 спрацювань правил і 4 нові факти.

### 2. Формулювання гіпотез
Сформовано чотири гіпотези щодо ймовірних зон несправності автомобіля:
- H1 — двигун або автоматична коробка передач (P).
- H2 — кузовні системи (B).
- H3 — шасі (C).
- H4 — взаємодія електронних блоків (U).

### 3. Зворотний ланцюг виведення
У файлі `src/inference.py` реалізовано перевірку гіпотез методом зворотного логічного виведення. Для коду P0300 підтверджено гіпотезу H1.

### 4. Підсистема пояснень
Реалізовано пояснення «ЧОМУ» для обґрунтування запитів до користувача та «ЯК» для відображення послідовності отримання діагностичного висновку.

### 5. Упорядкування за вартістю
Реалізовано визначення вартості отримання параметрів та впорядкування запитів за зростанням вартості.

### 6. Порівняльний експеримент

| Спосіб | Спрацювало правил | Запитів | Вартість | Висновок |
|---|---:|---:|---:|---|
| Прямий ланцюг | 10 | 0 | 0 | Двигун або АКПП |
| Зворотний без упорядкування | 2 | 2 | 3 | Двигун або АКПП |
| Зворотний з упорядкуванням | 2 | 2 | 3 | Двигун або АКПП |

### Висновок
У ході лабораторної роботи реалізовано механізми прямого та зворотного логічного виведення, підсистему пояснень і впорядкування запитів за вартістю. Усі три способи для тестового випадку P0300 сформували однаковий діагностичний висновок.
